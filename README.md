# Simple Interest Calculator

A simple calculator to calculate simple interest based on the principal amount, annual rate of interest, and time period.

## Description

This project calculates simple interest using the formula:

**Simple Interest = (Principal × Rate × Time) / 100**

## Inputs

* Principal amount
* Annual rate of interest
* Time period in years

## Output

* Calculated simple interest

## Usage

Run the `simple-interest.sh` script in a Bash terminal and enter the requested values.
